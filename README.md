# Ultra Liquid Glass PRO - Windows 11 Icon Pack Generator

Bộ công cụ tự động tạo bộ icon kính mờ bo góc (**Squircle Liquid Glass**) phát sáng nhẹ dành cho Windows 11, đồng bộ giao diện với gói *Ultra Liquid Glass PRO* trên Android.

## Cách sử dụng trên GitHub (Không cần cài Python trên máy)
1. Tạo một Repository mới trên GitHub (ví dụ: `win11-liquid-glass-icons`).
2. Upload toàn bộ file trong thư mục này lên Repository (bao gồm cả thư mục ẩn `.github/workflows/build.yml`).
3. Vào tab **Actions** trên GitHub -> chọn workflow **Build Liquid Glass Windows Icons** -> bấm **Run workflow**.
4. Chờ khoảng 20 giây cho chạy xong, kéo xuống mục **Artifacts** bên dưới và tải file `Ultra-Liquid-Glass-Windows-ICO.zip` về giải nén.

## Cách đổi icon trên Windows 11
1. Chuột phải vào shortcut phần mềm trên Desktop -> **Properties** -> thẻ **Shortcut**.
2. Chọn **Change Icon...** -> **Browse...** -> chọn file `.ico` tương ứng -> **OK** -> **Apply**.
